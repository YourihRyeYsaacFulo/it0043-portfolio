Personal Portfolio Website — Yourih Rye Ysaac Fulo

Overview
This project is a personal portfolio website created for my Introduction to Computing course. 
It presents information about me, my skills, and my interests as a Multimedia Arts student.

Features
Home, About, Skills, and Contact pages
Responsive layout for desktop, tablet, and mobile screens
Dark mode toggle with a saved theme preference
Hobbies section rendered dynamically using JavaScript
Contact form with individual input validation messages
Local Storage for portfolio settings
Live deployment using InfinityFree with HTTPS
Contact form limitation: The form validates input and displays validation messages, but it does not send messages to an email address or backend.

Technologies

CSS3
JavaScript

Git and GitHub

Setup
Clone or download this repository.
Open the project folder in Visual Studio Code.
Open index.html in a browser or use a local development server.
Navigate through the Home, About, Skills, and Contact pages to test the website.
This is a static front-end project and does not require a backend installation. A local development server is recommended for testing.

Local Storage
The portfolio uses the portfolioSettings Local Storage key to save the following settings:

theme: the selected display theme
visitorName: the stored visitor name
lastVisit: the recorded visit timestamp

To reset these settings, clear this site's Local Storage in the browser's developer tools. This removes the saved portfolio settings for that browser and site without clearing other browser data.
