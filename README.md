Project Title

Personal Portfolio Website

Overview
This project is a personal portfolio website created for my Introduction to Computing course.
It presents information about me, my skills, and my interests as a Multimedia Arts student.

Features
Home, About, Skills, and Contact pages
Responsive layout for desktop, tablet, and mobile screens
Dark mode toggle with saved theme preference
Hobbies section displayed using JavaScript
Contact form with input validation
Local storage for saving portfolio settings
Live deployment using InfinityFree with HTTPS

Technologies
HTML5
CSS3
JavaScript
Browser Local Storage
Git and GitHub
InfinityFree hosting

Setup
Download or clone this repository.
Open the project folder in Visual Studio Code.
Open index.html in a browser or use a local development server.
Navigate through the pages to test the website features.
No backend installation is required for the current static website.

https://fulo-portfolio.great-site.net/

AI assistance was used during the development of the portfolio, including help with HTML, CSS, JavaScript, debugging, local storage behavior, deployment preparation, and verification documentation.

I tested the website locally and on the live domain. My checks included page navigation, responsive layouts, dark mode, contact form validation, direct page URLs, HTTPS behavior, and browser Console errors.

Some limitations remain: the contact form validates input but does not deliver messages to a backend or email address, and the www domain variant displays a certificate warning. These issues were documented during deployment verification.
